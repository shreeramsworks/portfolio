# Design System — Shreeram Kulkarni Portfolio

## Brand
- **Tone:** Technical, confident, no-fluff
- **Audience:** Startup founders, tech leads, agency partners
- **Memorable thing:** "This person builds automation that actually works"

## Colors
```css
--bg: #0a0a0b          /* Deep background */
--bg-surface: #121214  /* Elevated surfaces */
--bg-card: #1a1a1e     /* Card backgrounds */
--bg-card-hover: #222228
--border: #2a2a30
--text-primary: #f4f4f5
--text-secondary: #a1a1aa
--text-muted: #6b6b7a
--accent: #22d3ee       /* Cyan - primary accent */
--accent-dim: #0891b2
--green: #4ade80        /* Status dot */
```

## Typography
- **Headings:** Inter (700–800 weight), tight letter-spacing -0.04em
- **Body:** Inter (400 weight), 1.6 line-height
- **Code/tags:** JetBrains Mono (monospace)

## Layout
- Max-width: 1100px content
- Sections: 100px vertical padding
- Cards: 12px border-radius, subtle borders, hover lift

## Design Principles
- Dark-first, noise texture overlay for depth
- Gradient accent text (cyan → purple → pink) on hero headline
- Cards with top gradient bar on hover
- Timeline with cyan dot indicators
- No stock imagery, no decorative blobs, no AI slop
